* **Nama Database:** `mabarvip_local`

* **File Konfigurasi:** `.env` (Lokal)

  ```env
  DIRECT_URL="postgresql://postgres:almigty007@localhost:5433/mabarvip_local"
  ```

  ```prisma
  }
  ```

## 3. Aturan Ketat (Strict Rules):
1. File `.env` lokal **HARUS SELALU** terhubung ke PostgreSQL lokal (`localhost:5433/mabarvip_local`).
2. Jangan pernah menimpa `.env` lokal dengan database Supabase production saat development.
3. Semua perubahan data, pengetesan mabar VIP, live settings, dan edit linktree di `localhost:3006` **100% masuk ke database PostgreSQL lokal**.
4. Database Production di Supabase **HANYA** akan berubah jika kamu login admin langsung di website production (`https://virtus-official.netlify.app/admin`).
