## 3. Aturan Ketat (Strict Rules):
1. **DILARANG** menghubungkan `.env` lokal ke Supabase PostgreSQL production.
2. Setiap perubahan data di localhost (tambah/edit/hapus player VIP, live stream setting, tema, linktree) **HANYA** tersimpan di database lokal PostgreSQL (`mabarvip_local`).
3. Database Production di Supabase **HANYA** terpengaruh jika admin login dan mengubah data di domain live production (`https://virtus-official.netlify.app/admin`).
4. Default fallback data profil di `src/app/page.tsx`, `src/app/api/linktree/route.ts`, dan `src/app/admin/edit-linktree/page.tsx` selalu menggunakan data resmi **Virtus Official** (bukan template default).
5. Perintah Sinkronisasi Schema:
   - Local: `npm run db:sync` (mendorong schema ke PostgreSQL lokal port 5433)
   - Generate: `npm run db:generate` (membuat Prisma client)
