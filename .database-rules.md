# 🛡️ ATURAN PEMISAHAN DATABASE LOCALHOST & PRODUCTION

Dokumen ini adalah aturan tetap untuk memisahkan database Localhost (Development) dan Production (Deployment).

---

## 1. Localhost (Development)
* **Tipe Database:** MySQL (Lokal XAMPP)
* **Host / Port:** `localhost:3306`
* **Nama Database:** `mabarvip_local`
* **File Konfigurasi:** `.env` (Lokal, **JANGAN** pernah isi dengan Supabase PostgreSQL!)
* **Connection String:**
  ```env
  DATABASE_URL="mysql://root:@localhost:3306/mabarvip_local"
  NEXTAUTH_URL="http://localhost:3006"
  ```
* **Prisma Schema Provider:**
  ```prisma
  datasource db {
    provider = "mysql"
    url      = env("DATABASE_URL")
  }
  ```

---

## 2. Production (Deploy / Netlify)
* **Tipe Database:** Supabase PostgreSQL (Cloud)
* **File Konfigurasi:** `netlify.toml` dan Netlify Dashboard Environment Variables.
* **Connection String di Netlify:**
  ```toml
  [build.environment]
  DATABASE_URL = "postgresql://postgres.xkslvfdguwvrhxetbmyw:...@aws-0-ap-southeast-1.pooler.supabase.com:6543/postgres?pgbouncer=true"
  NEXTAUTH_URL = "https://virtus-official.netlify.app"
  ```

---

## 3. Aturan Ketat (Strict Rules):
1. **DILARANG** menghubungkan `.env` lokal ke Supabase PostgreSQL production.
2. Setiap perubahan data di localhost (tambah/edit/hapus player, live stream setting, tema, linktree) **HANYA** masuk ke database MySQL lokal (`mabarvip_local`).
3. Database Production di Supabase **HANYA** terpengaruh jika admin login dan mengubah data di domain live production (`https://virtus-official.netlify.app/admin`).
4. Jika mengubah `.env` lokal, server dev Next.js (`npm run dev`) **HARUS di-restart** agar membaca file `.env` yang baru.
