# Aturan Push & Deployment (Penting!)

> [!IMPORTANT]
> **JANGAN PERNAH** melakukan `git push` atau deploy otomatis ke GitHub / Netlify setiap kali ada update/perubahan di localhost.

## Aturan Utama:
1. Semua pengujian, perbaikan, dan perubahan kode **hanya dilakukan secara lokal (localhost)**.
2. `git push` ke GitHub **HANYA** boleh dilakukan jika user sudah memberikan instruksi/perintah eksplisit untuk melakukan push (misalnya: *"suruh git push"*, *"push ke github"*, *"deploy sekarang"*).
3. Hal ini bertujuan untuk menghemat kredit/resource build di Netlify agar tidak terbuang sia-sia saat proses pengujian lokal.
