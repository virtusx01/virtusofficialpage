# 📐 Standar Desain Header, Footer & Spesifikasi Tata Letak Halaman (Mabar VIP)

Dokumen ini mendokumentasikan spesifikasi standar desain UI/UX, arsitektur header & footer, serta tata letak halaman komprehensif untuk platform **Mabar VIP By Virtus**.

---

## 🎨 1. Design System & Design Tokens

### Color Palette (Sleek Dark Theme)
- **Background Utama**: Slate 950 (`#020617`) & Slate 900 (`#0f172a`)
- **Accent Glow & Brand**:
  - Violet / Purple: `from-violet-600 to-indigo-600` (Brand Primary)
  - Fuchsia / Neon: `from-fuchsia-500 to-purple-600` (VIP Tier Highlight)
  - Emerald / Cyan: `from-emerald-400 to-cyan-500` (Live & Status Active)
  - Amber / Orange: `from-orange-500 to-amber-500` (Sociabuzz & Promo CTA)
- **Border & Glassmorphism**: `border-slate-800/80` dengan `backdrop-blur-md bg-slate-950/80`
- **Typography**: Font Sans modern (Geist Sans / Inter) dengan keterbacaan kontras tinggi (`text-slate-100`, `text-slate-300`, `text-slate-400`).

---

## 🧭 2. Spesifikasi Standar Header (`src/components/Header.tsx`)

Header dirancang agar konsisten, responsif, dan memberikan navigasi cepat antar fitur utama.

### Elemen Utama Header:
1. **Brand Logo & Avatar**:
   - Foto Profil Virtus dengan *glow accent border* (`border-violet-500/50`).
   - Judul Brand: **Mabar VIP By Virtus** (*Gradient Text*).
   - Tagline: *"DIJAMIN AUTO DIGENDONG EUYY"*.
2. **Menu Navigasi Utama**:
   - `Halaman Utama ( / )`: Mengarah ke Linktree Landing Page.
   - `Live Queue ( /mabarvip )`: Mengarah ke Dashboard Antrean VIP Mabar.
   - `Teks Berjalan ( /textberjalan )`: Mengarah ke Display OBS Running Text.
   - *State Active*: Menggunakan `usePathname()` untuk menandai menu aktif dengan background violet & indicator dot.
3. **Status Live Streaming Badge**:
   - Indikator pulsa merah **LIVE** jika streaming sedang berlangsung.
4. **Admin Quick Portal & Session**:
   - Tombol **Dashboard Admin** (`/admin/dashboard`) dan **Logout** jika sesi admin aktif.
   - Tombol **Login Admin** (`/admin`) jika belum terautentikasi.
5. **Mobile Navigation Drawer**:
   - Menu hamburger yang responsif pada layar kecil dengan animasi slide-down.

## 📄 3. Spesifikasi Tata Letak & Isi Halaman Utama

### A. Landing Page Utama (`/` - Linktree Landing)
- **Header**: Navigasi global terintegrasi di bagian atas.
- **Hero & Profile Card**:
  - Avatar lingkaran dengan ring neon.
  - Nama tampilan, bio profesional, dan badge verifikasi.
- **Theme Switcher Bar**: Pilihan cepat tema visual (Ocean, Midnight, Cyber Neon, Sunset, Glass).
- **Social Media Link Grid**: Tombol link sosial dengan vektor SVG resmi (WhatsApp Green & Dark, TikTok, Telegram, YouTube, Instagram, Facebook, LinkedIn, Twitter/X, GitHub, Discord).
- **Banner Live / Promo Card**: Kartu promo interaktif untuk bergabung ke antrean Mabar VIP.
- **Footer**: Footer universal di bagian bawah.

### B. Live Queue Page (`/mabarvip`)
- **Header**: Header navigasi global.
- **Stream Banner & Sociabuzz CTA**: Live stream player status & tombol order VIP via Sociabuzz.
- **Announcement Ticker**: Pengumuman berjalan real-time.
- **Filter & Search Bar**: Filter berdasarkan tipe VIP (End Live vs Per Match) dan pencarian Player ID.
- **Live Tracking 4-Grid Cards**:
  1. *Sedang Bermain (Playing)*: Player aktif di dalam match.
  2. *Daftar Antrean (Queue)*: Urutan antrean player VIP.
  3. *Tertunda (Pending/AFK)*: Status player yang dipause.
  4. *Selesai VIP (Completed)*: History player yang sudah menyelesaikan match.
- **Footer**: Footer universal dengan timestamp *Last Sync* real-time.

### C. Display Teks Berjalan (`/textberjalan`)
- **Layout**: Mode full-screen transparan/khusus OBS Overlay dengan opsi tampilan baris bergerak dan daftar player aktif.

### D. Admin Dashboard (`/admin/dashboard` & `/admin/edit-linktree`)
- **Header**: Header admin khusus dengan jalan pintas ke Editor Linktree, Manajemen Player, dan Logout.
- **Content**: Form konfigurasi komprehensif, input upload gambar avatar/banner ke Supabase Storage, dan tabel kontrol antrean.

## ⚓ 4. Spesifikasi Standar Footer (`src/components/Footer.tsx`)

Footer universal yang dihadirkan di semua halaman publik dan admin.

### Elemen Utama Footer:
1. **Brand Overview**: Logo Virtus, bio singkat, dan indikator status server.
2. **Navigasi Cepat**: Link cepat ke semua fitur (`Halaman Utama`, `Live Queue`, `Teks Berjalan`, `Portal Admin`).
3. **Sosial Media Official**: Link langsung ke WhatsApp, TikTok, YouTube, Instagram, dan Telegram resmi.
4. **Bottom Bar**: Hak Cipta © Mabar VIP By Virtus & Real-time Live Status Sync.
