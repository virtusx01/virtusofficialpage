# 📐 Standar Desain Header, Footer & Spesifikasi Tata Letak Halaman (Mabar VIP)

Dokumen ini mendokumentasikan spesifikasi standar desain UI/UX, arsitektur header & footer, serta tata letak halaman komprehensif untuk platform **Mabar VIP By Virtus**.

---

## 🎨 1. Design System & Design Tokens

### Color Palette (Sleek Dark Theme)
- **Background Utama**: Slate 950 (`#020617`) & Slate 900 (`#0f172a`)
- **Accent Glow & Brand**:
  - Violet / Purple: `from-violet-600 to-indigo-600` (Brand Primary)
  - Fuchsia / Neon: `from-fuchsia-500 to-purple-600` (VIP Tier Highlight)
  - Emerald / Cyan: `from-emerald-400 to-cyan-500` (Queue & Status Active)
  - Red Pulse: `from-red-600 to-pink-600` (Live Streaming Active)
- **Border & Glassmorphism**: `border-slate-800/80` dengan `backdrop-blur-md bg-slate-950/80`
- **Typography**: Font Sans modern (Geist Sans / Inter) dengan keterbacaan kontras tinggi (`text-slate-100`, `text-slate-300`, `text-slate-400`).

---

## 🧭 2. Spesifikasi Standar Header (`src/components/Header.tsx`)

Header dirancang agar konsisten, bersih, dan fokus pada navigasi pengunjung utama tanpa menampilkan opsi login admin publik.

### Elemen Utama Header:
1. **Brand Logo & Avatar**:
   - Foto Profil Virtus dengan *glow accent border* (`border-violet-500/50`).
   - Judul Brand: **Mabar VIP By Virtus** (*Gradient Text*).
   - Tagline: *"DIJAMIN AUTO DIGENDONG EUYY"*.
2. **Menu Navigasi Utama**:
   - `Halaman Utama ( / )`: Mengarah ke Linktree Landing Page.
   - `Mabar VIP ( /mabarvip )`: Mengarah ke Dashboard Antrean VIP Mabar.
   - *State Active*: Menggunakan `usePathname()` untuk menandai menu aktif dengan background violet.
3. **Auto-Detecting Live / Queue Badge**:
   - Secara otomatis mendeteksi status live streaming dari API `/api/settings`.
   - **LIVE**: Menampilkan badge merah dengan titik pulsa animasi saat streaming aktif.
   - **QUEUE**: Menampilkan badge emerald saat mode antrean biasa (stream offline).
4. **Opsi Admin (Sesi Terautentikasi)**:
   - Opsi `Admin Login` disembunyikan untuk pengunjung umum.
   - Tombol **Dashboard Admin** (`/admin/dashboard`) dan **Logout** hanya akan tampil jika admin sudah login.
5. **Mobile Navigation Drawer**:
   - Menu hamburger yang responsif pada layar kecil dengan animasi slide-down.

## 📄 3. Spesifikasi Tata Letak & Isi Halaman Utama (Mobile-First Tailwind CSS)

Semua halaman dirancang menggunakan pendekatan **Mobile-First** (`class="p-4 md:p-8"`, `grid-cols-1 md:grid-cols-3`, `hidden md:flex`, dsb.) untuk performa optimal di perangkat HP & Desktop.

### A. Landing Page Utama (`/` - Linktree Landing)
- **Header**: Navigasi global terintegrasi di bagian atas dengan Mobile Drawer menu hamburger.
- **Hero & Profile Card**: Avatar lingkaran, nama tampilan, bio profesional.
- **Theme Switcher Bar**: Pilihan cepat tema visual (Ocean, Dark, Neon, Sunset, Glass).
- **Social Media Link Grid**: Tombol link sosial dengan vektor SVG resmi (WhatsApp Green & Dark, TikTok, Telegram, YouTube, Instagram, Facebook, LinkedIn, Twitter/X, GitHub, Discord).
- **Banner Live / Promo Card**: Kartu promo interaktif untuk bergabung ke antrean Mabar VIP.
- **Footer**: Footer universal di bagian bawah.

### B. Live Queue Page (`/mabarvip`)
- **Header**: Header navigasi global.
- **Stream Banner & Sociabuzz CTA**: Live stream player status & tombol order VIP via Sociabuzz.
- **Announcement Ticker**: Pengumuman berjalan real-time.
- **Filter & Search Bar**: Filter berdasarkan tipe VIP (End Live vs Per Match) dan pencarian Player ID.
- **Live Tracking 4-Grid Cards**:
  1. *Sedang Bermain (Playing)*: Player aktif di dalam match.
  2. *Daftar Antrean (Queue)*: Urutan antrean player VIP.
  3. *Tertunda (Pending/AFK)*: Status player yang dipause.
  4. *Selesai VIP (Completed)*: History player yang sudah menyelesaikan match.
- **Footer**: Footer universal.

### C. Galeri Album Fanbase (`/fanbase-cupidut-dudud`)
- **Header**: Header navigasi global.
- **Hero Header**: Banner informasi album kucing kesayangan Virtus (**Cupidut**: Abu-abu & **Dudud**: Oren Belang).
- **Filter Album**: Tab switcher untuk melihat Semua Foto, Album Cupidut (Abu-abu), atau Album Dudud (Oren Belang).
- **Photo Grid Gallery**: Tampilan grid foto responsif dengan effect hover zoom, card glassmorphism, dan badge tipe kucing.
- **Lightbox Preview**: Popup zoom detail foto saat diklik.
- **Footer**: Footer universal.

### D. Admin Dashboard & Editor (`/admin/dashboard`, `/admin/edit-linktree`, `/edit/fanbase-cupidut-dudud`)
- **Header**: Header admin khusus dengan jalan pintas ke Editor Linktree, CRUD Fanbase Cat, Manajemen Player VIP, dan Logout.
- **CRUD Fanbase Cat (`/edit/fanbase-cupidut-dudud`)**:
  - Modal form Tambah & Edit foto kucing.
  - Pilihan tipe kucing: `CUPIDUT` (Abu-abu) vs `DUDUD` (Oren Belang).
  - Input Upload gambar langsung ke Supabase Storage via `/api/upload`.
  - Hapus foto & reorder album.
