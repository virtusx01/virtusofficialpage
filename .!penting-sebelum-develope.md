## 🔗 4. Fitur Sub-Judul / Kategori per Link (Grouping Tombol)

Kamu bisa mengelompokkan tombol link di bawah **sub-judul / kategori** yang berbeda-beda.

### Cara Pakai:
Buka halaman **Admin → Edit Linktree → Bagian "Daftar Tombol & Link"**.

Setiap link punya input **"Sub-Judul / Kategori (opsional)"**:

| Sub-Judul Diisi | Sub-Judul Kosong | Hasil di Tampilan |
| :--- | :--- | :--- |
| `Top Up` | - | Muncul badge **"TOP UP"** sebelum link tersebut |
| `Komunitas` | - | Muncul badge **"KOMUNITAS"** sebelum link tersebut |
| *(kosong)* | *(link pertama)* | Muncul header default dari kolom **"Judul Header Sosial"** di Informasi Profil (contoh: *"Social Media Handles"*) |
| *(kosong)* | *(bukan link pertama)* | Tidak muncul sub-judul baru; ikut ke grup sebelumnya |

### Contoh Setup:

```
Link #1: TikTok     → Sub-Judul: (kosong)
Link #2: YouTube    → Sub-Judul: (kosong)
Link #3: Astra Points → Sub-Judul: Top Up
Link #4: Diamond Store → Sub-Judul: Top Up
```

**Hasil tampilan:**
```
── SOCIAL MEDIA HANDLES ──  (dari kolom Judul Header Sosial)
  🎵 TikTok
  ▶️  YouTube
── TOP UP ──
  🪙 Astra Points
  💳 Diamond Store
```

### Kustomisasi Judul Header Utama:
Di halaman admin **Informasi Profil**, cari kolom **"Judul Header Sosial Media"** untuk mengubah teks dari *"Social Media Handles"* menjadi teks apapun yang kamu mau.
