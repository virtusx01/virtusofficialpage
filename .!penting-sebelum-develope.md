# 🚨 PENTING SEBELUM DEVELOP / RUN PROJECT

Panduan ini wajib dibaca agar tidak salah koneksi database saat coding di localhost vs saat deploy ke Production.

---

## 📁 1. Struktur File Environment (.env)

| File | Target Environment | Database | URL / Port |
| :--- | :--- | :--- | :--- |
| **`.env`** | **Localhost / Development** | PostgreSQL 18 Lokal | `localhost:5433` (`mabarvip_local`) |
| **`.env.prod`** | **Production (Backup/Ref)** | Supabase Cloud | `aws-0-ap-southeast-1.pooler.supabase.com` |

> ⚠️ **PENTING:** 
> File `.env` aktif di laptop kamu sekarang sudah terhubung ke **PostgreSQL Lokal (`localhost:5433/mabarvip_local`)**.  
> Apapun yang kamu tambah, edit, atau hapus di `http://localhost:3006/admin` **HANYA akan masuk ke database lokal** dan **TIDAK AKAN menyentuh database production di Supabase**.

## 🛠️ 4. Perintah Berguna Saat Development

* **Menjalankan Website Lokal:**
  ```bash
  npm run dev
  ```
* **Sinkronisasi Skema Baru ke DB Lokal:**

## 🔗 5. Fitur Kustomisasi Sub-Judul Link (Social Media, Top Up, dll)
* **Kustomisasi Judul:** Kamu bisa mengubah teks header default `Social Media Handles` di menu Profil Admin.
* **Sub-Judul Per Tombol Link:** Pada setiap tombol link (misal: *Astra Points*, *Diamond Store*, dll), tersedia kolom **Sub-Judul / Kategori**:
  - Jika diisi `Top Up`, maka link tersebut akan otomatis memiliki pill header tersendiri bertuliskan **TOP UP**.
  - Jika 2 link berturut-turut memiliki Sub-Judul yang sama (misal *Social Media*), keduanya akan otomatis dikelompokkan dalam 1 subjudul yang rapi.
